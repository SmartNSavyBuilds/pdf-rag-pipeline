# PDF RAG Pipeline

Retrieval-augmented generation over three NIST AI and security documents. The notebook loads PDF pages, splits their text into overlapping chunks, creates OpenAI embeddings, stores them in FAISS, retrieves passages relevant to a question, and optionally uses GPT to answer from the retrieved passages.

## Project files

- `rag_pipeline.ipynb` - the executed pipeline and sample outputs
- `pdfs/` - the three source PDFs: NIST AI RMF, NIST SP 800-218, and NIST SP 1270
- `faiss_index/` - the locally saved vector index, which can be regenerated by running the notebook

## Run the notebook

1. Open `rag_pipeline.ipynb` in VS Code and select the Python kernel at `C:\claw-code\.venv\Scripts\python.exe`.
2. Make sure `OPENAI_API_KEY` is set in the environment. Do not put the key in this notebook or include it in the submission.
3. Run the notebook cells from top to bottom. The embeddings and optional GPT answer use the OpenAI API.
4. Edit `sample_query` in Step 4 to ask a question about the PDFs, then rerun Steps 4 and 5.

## Current sample results

- Chunk size: 1,000 characters; overlap: 150 characters
- Chunks: 577
- Average chunk size: 834 characters (range: 76-1,000)
- Sample query: “What are some risks that can arise with improper use or software development?”

Results can change if the documents, query, or chunking settings change.
